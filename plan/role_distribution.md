# 역할별 업무 분배 및 분류 (Role Distribution)

## 프로젝트 개요
**AllTimePrice Personal** 프로젝트는 사용자가 쇼핑몰의 가격 변동을 추적하고 최적의 구매 시점을 결정할 수 있도록 돕는 로컬 기반 개인화 서비스입니다.

---

## 1. 프로젝트 매니저 (PM) & 아키텍트
**역할**: 전체 방향성 설정, 일정 관리, 기술적 의사결정 조정
- [x] **기획 및 설계**: 요구사항 분석, 3단 레이아웃 UI 설계, DB 스키마(1:N 구조) 수립 완료.
- [x] **규칙 수립**: "모든 문서는 한국어", "프리미엄 UI 지향", "Clean & Hybrid 데이터 수집" 원칙 확립.
- [ ] **문서 최적화**: `task.md`, `todo.md`를 최신 상태(API 중심 전략)로 동기화.
- [ ] **리스크 관리**: 크롤링 차단 이슈에 대응하여 '네이버 쇼핑 API 전용 모드'로의 전환 결정(안정성 확보).

## 2. 백엔드 개발자 (Backend Developer)
**역할**: 데이터 수집 엔진, API 서버, DB 관리
- [x] **기본 구축**: Node.js/Express 서버 환경 구성, Supabase 연동.
- [x] **외부 연동**: 네이버 쇼핑 API 연동 (`naver_api.js`), Puppeteer 스텔스 모드 구현.
- [ ] **엔진 경량화 (Immediate)**:
    - `crawler.js`에서 불안정한 Puppeteer 로직 비활성화.
    - 네이버 API 전용 검색 파이프라인 최적화.
- [ ] **API 개발**:
    - 프론트엔드 연동을 위한 `/api/search`, `/api/products` 엔드포인트 안정화.
    - 상품 추가/수정/삭제 로직 DB 연결.

## 3. 프론트엔드 개발자 (Frontend Developer)
**역할**: 사용자 인터페이스 구현, 상태 관리, 시각적 경험 최적화
- [x] **UI 구축**: React/Vite 기반 대시보드, 차트(Recharts), 타임라인 알림 UI 구현 완료.
- [x] **UX 개선**: 쇼핑몰 바로가기(아이콘), 상품 카드 압축, 커스텀 스크롤바 적용.
- [ ] **데이터 바인딩**:
    - 기존 Mock 데이터 시스템을 실제 백엔드 API 호출(`fetch`)로 교체.
    - 로딩 상태(Loading skeleton) 및 에러 처리(Toast notification) 추가.
- [ ] **디자인 폴리싱**: 프리미엄 감성을 위한 미세 애니메이션 및 반응형 레이아웃 보정.

## 4. QA 및 DevOps 엔지니어
**역할**: 테스트 자동화, 시스템 안정성 검증, 배포 환경 관리
- [x] **테스트 도구**: `debug_system.js` 등 진단 스크립트 작성.
- [ ] **안정성 검증**:
    - 네이버 API 키 유효성 및 할당량 모니터링 체계 구축.
    - 검색 속도 및 정확도 테스트 (목표: 검색 후 1초 이내 결과 렌더링).
- [ ] **배포 준비**: 로컬 실행 가이드(README) 작성 및 환경 변수(.env) 템플릿화.

---

## 🚀 금일 집중 업무 (Sprint Goal)
**"서비스 안정화 및 실데이터 연동"**
1. **(Backend)** Puppeteer를 걷어내고 네이버 API로만 작동하도록 서버 로직 수정.
2. **(Frontend)** 백엔드 API와 프론트엔드 검색창 연결 및 실제 데이터 출력 확인.
3. **(QA)** 통합 테스트 수행.
