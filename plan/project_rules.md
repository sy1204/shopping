# 프로젝트 규칙 (Project Rules)

## 1. 언어 (Language)
- 본 프로젝트의 모든 대화, 문서, 워크플로우, 결과물(코드 주석, UI 텍스트 등)은 반드시 **한국어(Korean)**로 작성한다.

## 2. 디자인 (Design)
- 완성도 높은 사용자 경험(UX)을 제공해야 하며, 시각적으로 세련된 **프리미엄 디자인(깨끗한 화이트 UI, 상품 이미지 강조 등)**을 지향한다.
- 단순한 기능 구현을 넘어 사용자가 '사고 싶게 만드는' 인터페이스를 구축한다.

## 3. 개인화 (Personalization)
- 사용자의 로컬 환경에서 구동되는 개인화 도구로서의 특성을 유지한다.
- 데이터는 가급적 로컬(SQLite 등)에 저장하여 개인 정보를 보호하고 접근성을 높인다.
