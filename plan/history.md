# AllTimePrice Personal - UI/UX 수정 및 기능 구현 기록

이 문서는 사용자 요청에 따라 진행된 주요 UI/UX 개선 및 기능 구현 내역을 요약하여 기록합니다.

---

## 1. 전반적인 레이아웃 및 디자인 개선
- **상품 카드 압축**: 정보 밀도를 높이기 위해 카드 내부 패딩 및 간격을 줄여 세로 공간의 효율성 극대화.
- **희망가 설정 UI 최적화**: 텍스트와 입력창을 한 줄로 배치하고, 고액 입력(예: 1,000,000원)이 가능하도록 입력칸 너비를 65px에서 90px로 확장.
- **알림 아이콘 고도화**: 기존 체크박스를 `Bell` 아이콘으로 교체. 알림 활성화 시 초록색 채우기 및 `animate-pulse` 효과를 적용하여 시각적 피드백 강화.
- **상단 헤더 정리**: 불필요해진 상단 중앙 검색바를 제거하고 알림 센터(종 아이콘)만 깔끔하게 비치.

## 2. 핵심 기능 고도화
- **쇼핑몰 최저가 자동 선택**: 상품 선택 시 해당 상품의 연동 쇼핑몰 중 가장 가격이 낮은 곳이 자동으로 선택되도록 로직 수정.
- **명시적 메모 시스템**: 
    - "나의 메모" 섹션 추가 (연노란색 메모지 디자인 적용).
    - '수정' 버튼 클릭 시 편집 모드로 전환, '저장' 버튼 클릭 시 확정되는 명시적 저장 시스템 구축.
- **상품 상세 정보(Specs) 표시**: 크롤링된 성분, 규격, 보관 방법 등을 표 형식으로 보여주는 상세 정보 섹션 추가.

## 3. 지능형 쇼핑몰 및 이미지 연동
- **이미지 자동 수집**: 상품 등록 시 키워드(햇반, 노트북 등)를 분석하여 실제 상품 이미지(Unsplash 등)를 자동으로 매핑하고 표시.
- **URL 기반 쇼핑몰 추가**: 
    - 쇼핑몰 주소(URL)만 입력하고 엔터를 치면 사이트 도메인을 분석하여 쇼핑몰 이름(Coupang, 11번가 등)을 자동으로 인식하여 등록.

## 4. 통합 검색 및 위치 변경
- **검색창 사이드바 이동**: 검색창을 상단에서 왼쪽 사이드바 '내 관심 상품' 하단으로 이동하여 접근성 향상.
- **5대 쇼핑몰 통합 검색**: 
    - 검색 시 쿠팡, 네이버, 지마켓, 옥션, 11번가의 실시간 가격 정보를 시뮬레이션하여 중앙 대시보드에 즉시 표시.
    - 검색 결과 화면에서 '+ 관심 등록' 버튼을 통해 한 번의 클릭으로 상품을 추적 리스트에 추가 가능.

## 5. 왼쪽 사이드바 개편 및 정밀 UI 최적화 (New)
- **불필요한 기능 제거**: "검색해서 찾기" 대신 "URL 직접 등록" 방식으로 전환함에 따라, 왼쪽 사이드바의 '통합 검색창'과 '최근 검색어' 섹션 제거.
- **쇼핑몰 바로가기 채널 신설**: 
    - 왼쪽 상단에 쿠팡, 네이버, 지마켓, 11번가, 옥션의 **공식 로고 아이콘** 배치.
    - 클릭 시 해당 쇼핑몰 새 탭 열기 → URL 복사 → 우측 등록의 직관적인 흐름 완성.
- **아이콘 디자인 정밀 보정**:
    - 외부 URL 대신 로컬 고화질 이미지(`public/icons`) 적용.
    - 11번가, 옥션 아이콘의 여백을 제거한 **Full-bleed 이미지** 교체.
    - 모든 아이콘의 시각적 크기가 균일하도록 **0.9배~0.95배 미세 축소(Optimization)** 적용.
- **디테일 잘림 현상 수정**:
    - 왼쪽/오른쪽 사이드바 컨테이너에 내부 패딩(`padding: 4px`)을 추가하여 강조 테두리(Border)나 그림자(Shadow)가 잘리는 현상 해결.
    - 리스트 하단에 여백(`padding-bottom`)을 확보하여 스크롤 시 마지막 항목 가려짐 방지.
- **사용자 인증 UI**: 상단 헤더에 로그인/로그아웃 버튼 및 프로필 UI 추가 (PC/모바일 반응형 동작).

## 6. 백엔드 시스템 구축 및 크롤링 차단 우회 (New) - 2025.12.26
- **쿠팡 차단 우회 (하이브리드 크롤링)**: 
    - 직접 접속 차단 시 자동으로 **구글 검색 결과(Snippet)**에서 정보를 추출하는 폴백(Fallback) 로직 구현.
    - 접근 거부(403) 상황에서도 상품명과 가격을 안정적으로 수집 성공.
- **모바일 단축 URL 대응**: `link.coupang.com` 형태의 모바일 주소를 실제 상품 페이지로 리다이렉션 추적하여 처리하도록 개선.
- **실시간 단계별 로깅**: 수집 과정을 [단계 1] 접속 -> [단계 2] 우회 등 사용자가 파악하기 쉽게 한글 로그 시스템 보강.
- **DB 아키텍처 고도화 (Supabase)**:
    - 1개 상품에 다수 쇼핑몰 URL을 연결하는 1:N 구조 설계 및 SQL 테이블 생성.
    - 검색 결과를 DB에 자동 매칭하여 저장하는 배치 프로세스 구현.
- **공식 API 연동 및 설계 원칙 수립**:
    - **네이버 쇼핑 검색 API** 도입 (`naver_api.js`): 크롤링 대비 속도와 안정성 대폭 향상.
    - **Clean & Hybrid 설계 원칙**: 이미지 AI 변환(나노바나나 등), 사실 기반 텍스트 추출, 원본 딥링크 유지 전략 수립으로 저작권 및 약관 리스크 최소화.
- **동적 크롤링 기술 고도화 (인간 행동 모사)**: (오후 작업 추가)
    - **Ghost Cursor & Scroll**: 로봇 탐지를 회피하기 위해 마우스 베지어 곡선 이동 및 불규칙 스크롤링 로직 추가.
    - **시스템 진단 도구 개발**: API 연결 상태와 브라우저 구동 여부를 동시에 점검하는 `debug_system.js` 스크립트 작성 및 테스트.
    - **이슈 사항**: 현재 환경 변수 로딩 문제(추정) 및 크롤러 타임아웃으로 인한 실행 지연 현상 확인 -> 익일 서버 재기동 및 최적화 예정.
