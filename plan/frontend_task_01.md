# 작업 지시서: 프론트엔드 API 연동 (FE-001)

**수신**: @frontend (프론트엔드 담당)
**발신**: @project_manager (프로젝트 매니저)
**우선순위**: 높음

## 개요
현재 프론트엔드는 하드코딩된 Mock 데이터를 사용하고 있습니다. 백엔드의 네이버 검색 API가 안정화되었으므로, 이를 프론트엔드와 연동하여 사용자가 실제 상품을 검색하고 결과를 볼 수 있도록 수정해야 합니다.

## 상세 작업 내용

### 1. Mock 데이터 제거 및 API 클라이언트 설정
- `price-tracker/src` 내부의 Mock 데이터 로직을 주석 처리하거나 제거하십시오.
- `axios` 또는 `fetch`를 사용하여 백엔드 API (`http://localhost:3000/api/search`)를 호출하는 로직을 작성하십시오.

### 2. 검색 기능 연동
- 사용자가 검색어를 입력하고 검색 버튼(또는 엔터)을 누르면 `/api/search` 엔드포인트를 호출하십시오.
- 반환된 결과(JSON)를 파싱하여 검색 결과 리스트에 표시하십시오.
- 로딩 중일 때 사용자에게 피드백(스켈레톤 UI 또는 Spinner)을 제공하십시오.

### 3. 데이터 구조 매핑
- 백엔드에서 반환하는 데이터 구조(`{ title, price, link, image, mall }`)를 프론트엔드 컴포넌트(`ProductCard` 등)의 Props에 맞게 매핑하십시오.

## 참고 사항
- 백엔드 서버 포트: `3000`
- 프론트엔드 개발 서버 포트: `5173` (CORS 문제 발생 시 `vite.config.js` 프록시 설정 확인 필요)
- 디자인 가이드를 준수하여 프리미엄 UI 감성을 유지하십시오.
